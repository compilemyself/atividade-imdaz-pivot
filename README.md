Proposta de atividade desenvolvida por Willian para aplicação com os alunos do 5º ano do **Instuto de Menores Dom Antônio Zattera**.

A atividade consiste na criação individual de uma animação utilizando o **Pivot Stick Figure Animator v5**.

**Para realizar a atividade, os alunos devem:**
- Criar uma animação com uma narrativa simples.
- Incluir pelo menos três caixas de texto.
- Salvar manualmente o arquivo produzido, incluindo seu nome no arquivo `.piv`

Neste repositório, estão disponíveis modelos de figuras (`.stk`) para auxiliar na criação das animações, além de uma animação de exemplo desenvolvida por mim.
